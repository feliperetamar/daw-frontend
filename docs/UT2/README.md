# Actividad 1. Cálculo de calificación

Realiza una página web que pida al usuario una nota numérica (en el rango 0 a 10 y con posibilidad de tener decimales) y responda al usuario la calificación textual (suspenso, aprobado, bien, notable o sobresaliente) correspondiente a la nota introducida.

Además, se deberá gestionar posibles errores. Por ejemplo, si se introduce una cadena de texto en lugar de un número.

# Actividad 2. Depuración

Se deberá hacer uso de las herramientas de depuración para comprobar el comportamiento correcto de la actividad 1 cuando se le introduce el valor de 5,5. Se debe:

- Crear y utilizar un punto de ruptura (break point).
- Moverse a través del flujo de un script.
- Comprobar el valor de una variable.

# Actividad 3. Funciones

Realiza las siguientes funciones en JavaScript y muestra su funcionamiento:

- Factorial de un número positivo.
- Calcula la media aritmética de una lista de números
- Calcula si una cadena de texto es o no un palíndromo. Ejemplo de palíndromo complejo: "La ruta nos aporto otro paso natural".
- Calcular si un DNI pasado como cadena es o no valido. Se debe comprobar tanto el número de caracteres adecuado (8 numéricos y 1 carácter) y si el carácter es el correcto.

# Actividad 4. Documentación con JSDoc

Utiliza JSDoc para documentar las funciones realizadas en la actividad anterior y genera la documentación.

# Actividad 5. Calculadora

Realiza un web que haga uso de JavaScript para operar como una calculadora simple.

- Permitir al usuario introducir dos valores mediante un formulario (valor 1 y valor 2).
- Permitir seleccionar una de las siguientes operaciones matemáticas: suma, resta, multiplicación, división, módulo y potencia.
- El resultado debe aparecer dentro de una etiqueta <h1 id="resultado">
- Comprobar si hay algún valor erróneo para la operación matemática seleccionada. Por ejemplo, dividir por cero.
- Para el cálculo de la potencia se debe hacer uso de bucles y no del operador \*\*.

# Actividad 6. Hola TypeScript: ¿Es mayor de edad?

Crea una página web utilizando TypeScript que dado un valor numérico, introducido por un input, muestre en pantalla si el usuario es mayor o menor de edad. También debe avisar de posibles errores.
